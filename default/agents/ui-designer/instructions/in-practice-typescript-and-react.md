Applies when the repository uses TypeScript with React (Remix, React Router, Next.js or similar). Name in the specification the units the builder already has.

- `null` means "absent" at a boundary; `throw` is for a programmer or configuration error. So "absent" needs a designed state, and "threw" is the system's failure screen.
- Tests assert exact names and sentences and select controls by role and label, which is why new inputs get `aria-label`s. So the wording in `product-design.md` is an input to tests. Write it exactly.
